### 为什么第 4 项不能自动化

- 我不能注册 Reddit/X/Indie Hackers 账号去发帖或私信：需要真人身份，且多数社区禁止未披露的推广，账号会被封。
- 「愿意付 $5」是一个人对另一个人的承诺。AI 伪造问卷、编造访谈记录，会直接毁掉整个项目的验证基础。
- 就算我用 AI 模拟 5 个用户，得到的也只是我自己的假设，不是市场信号。

**所以这周的计划不能「全部自动化」。能自动化的是「准备 + 研究 + 产出物」，不能自动化的是「市场信号」。**

## 3. 三个改变判断的发现

### 发现 1：原来的定位打不中人

Sentry 免费版是 **1 用户 / 5,000 errors/月 / 30 天保留 / 无限项目 / 邮件告警 / $0**。

目标用户是独立开发者，他们本来就在用免费版。「比 $26 便宜 80%」是在跟一个他们没买的套餐比价。

**结论：卖点从「便宜」改为「额度不焦虑 + 一个收件箱管所有项目 + 3 分钟接入」。**

### 发现 2：$5 确实是市场空位，但赛道在变挤

| 产品 | 免费额度 | 最低付费档 |
|---|---|---|
| Sentry | 5K/月，1 用户 | $26/月 |
| GlitchTip | 1K/月 | $15/月 |
| Bugsink | 15K/月 | €16/月 |
| Telebugs | 无 | $99/月托管 / $299 一次性自建 |
| 我们 | 5K/月 | **$5/月** |

$5 是最低的托管付费档，比第二名便宜 3 倍。但过去一年出现了 Bugsink、Telebugs、GlitchTip 三个同类替代品，这不是蓝海。

### 发现 3：「不限事件」有单位经济风险

$5/月不限事件，如果真按条存，一次 bug 风暴就能打穿成本。

**必须靠 issue 分组 + 每个 issue 最多存 50 条样本 + 项目级限流**，才能让固定价成立。这不是营销问题，是第 3 周必须写进 SDK/后端的架构约束。

按 100K events/月估算，存储约 75MB/月（压缩后），90 天约 225MB；Supabase 免费 500MB 只能撑 2 个重度用户，盈亏平衡约 5 个付费用户。**这是财务上最脆弱的一环。**

## 4. 需要你决策的 6 件事

| # | 决策 | 选项 | 我的建议 | 影响 |
|---|---|---|---|---|
| D1 | 主目标用户 | 仅独立开发者 / 独立开发者 + 2-3 人小团队 | **先只做独立开发者** | 加小团队要多用户系统，MVP 多 3-5h |
| D2 | 免费版额度 | 1 项目 + 5K/月 + 7 天 / 2 项目 + 5K/月 + 30 天 | **1 项目 + 5K + 7 天** | 7 天保留是升级动机；给太多会没人付费 |
| D3 | 「不限事件」怎么表达 | 字面 unlimited / 「无额度账单，自动合并采样」 | **后者** | 字面 unlimited 遇限流会打脸；后者可进 FAQ |
| D4 | SDK 路线 | 自写极简 JS SDK / 兼容 Sentry SDK 协议 | **MVP 自写，第 5-6 周再考虑兼容** | 兼容 Sentry 能降低迁移摩擦，但至少多 1 周 |
| D5 | 价格档位 | 只有 $5 / $5 + $12 团队档 | **MVP 只有 $5** | 多一档多一倍解释成本 |
| D6 | 品牌名 / 域名 | Bugpocket（占位）/ 其他 | **你先挑 2-3 个候选，我下周查域名和商标** | 影响域名、Logo、文案、社媒账号 |

**只有 D1-D6 都定了，第 2 周的 Landing Page 才不会返工。** 其中 D3 和 D5 最影响钱。

## 5. 你还需要做的两件事（约 1.5-2 小时）

### A. 人工验证（90 分钟，必须做）

按 `docs/08-第1周-人工验证工具包.md` 执行：10 次触达 → 3-5 次 15 分钟对话 → 填记录表。

过关线：**3 个人明确说「现在就会付 $5」**。只有「听起来不错 / 想先试用」不算。

### B. 竞品手感（35 分钟，可选但建议）

我用桌面研究替代了「深度体验」，但有两点只有亲手用才知道：接入到底几分钟、错误分组到底准不准。压缩成 35 分钟：

**Sentry（20 分钟）**

- [ ] 注册免费版，建 1 个项目
- [ ] 用一个本地 HTML 页面接 SDK，连续抛 3 种不同错误
- [ ] 看：分组是否把同类错误合并；从接入到看到第一条错误花了多久
- [ ] 看：免费额度用完时界面怎么提示（找 Billing → Usage）
- [ ] 记 3 条：最爽的 1 点、最烦的 2 点

**GlitchTip（15 分钟）**

- [ ] 注册托管免费版（1K events/月），走一遍建项目 + 接 SDK
- [ ] 只看：UI 完成度、接入步骤、错误详情页信息量
- [ ] 记 1 条：它哪里让你想「这个我自己做能更好」

> 不做这一步也能进第 2 周，但你对「3 分钟接入」和「分组质量」的判断会是二手的。这两个恰好是产品的核心承诺。

## 7. 风险清单（直说）

1. **最大风险不是没人做，是 Sentry 免费版够用。** 如果你的访谈对象大多没烧过额度、只有 1 个项目，这个产品对他们没有价值。
2. **$5 定价要求获客成本接近 0。** 100 个付费用户才 $500 MRR；投任何广告都会亏。
3. **固定价 + 不限事件是成本地雷。** 第 3 周不把分组/采样/限流写进架构，后面一定返工。
4. **4 周 MVP 容易膨胀。** 任何「顺手加个 Slack 通知」都会让发布推迟一周。
5. **竞品在增加。** 2025-2026 年已出现 3 个同类项目，先发优势没有想象中大。
