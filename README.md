给独立开发者的极简错误监控 — $5/月不限事件数，比 Sentry 便宜 80%。

- **给谁做**：有副业项目的独立开发者、1-3 人的小团队

- **核心差异**：便宜、简单、固定月费不超支
- **定价**：$5/月起
