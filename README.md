## 🎯 产品定位

- **给谁做**：有副业项目的独立开发者、1-3 人的小团队
- **解决什么**：线上出了 bug 不知道，等用户反馈才发现
- **跟 Sentry 的区别**：便宜 80%（$5 vs $26）、功能精简 80%、只做最核心的错误监控
- **定价**：$5/月起

## 🛠 技术栈

- 前端：Next.js + Tailwind CSS
- 后端：Next.js API Routes
- 数据库：Supabase (PostgreSQL)
- 部署：Vercel
- 支付：Lemon Squeezy
- 邮件：Resend
